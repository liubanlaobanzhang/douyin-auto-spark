## 环境注意（Windows + WorkBuddy 沙箱）
- 本环境 pnpm（corepack 11.19.0）install 必然失败：WorkBuddy 把 Node 的 fs.unlink 劫持为回收站操作（genie-safe-delete shim），pnpm 清理 `_tmp_*` 临时目录时 trash 失败，`PNPM_CONFIG_SAFE_DELETE=false` 和禁用沙箱都无法绕过。
- 解决办法：用 npm 安装依赖：`node node_modules/npm/bin/npm-cli.js install --no-package-lock`（避免生成 package-lock.json 污染 pnpm 项目）。
- pnpm 命令不在 PATH，需经 corepack 调用；本地二进制校验用 `node node_modules/<pkg>/bin/...`。
